# 🧮 Simple Calculator (C++)

A basic C++ console-based calculator that performs arithmetic operations: addition, subtraction, multiplication, and division based on user input.

## 💡 Features

- Supports basic arithmetic operations: `+`, `-`, `*`, `/`
- Takes two numbers as input from the user
- Displays the result of the operation
- Handles invalid operator input

## 🛠️ Technologies Used

- C++
- Standard Input/Output (`iostream`)
- Switch-case control structure

## 🧾 How to Run

### 💻 Compile and Execute

Make sure you have a C++ compiler installed like `g++`.

```bash
g++ -o calculator calculator.cpp
./calculator
```

Or if you're using Windows Command Prompt:

```bash
g++ -o calculator.exe calculator.cpp
calculator.exe
```
